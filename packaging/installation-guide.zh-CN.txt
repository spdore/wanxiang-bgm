万象 BGM 播放器 · Windows 64 位安装版
版本：1.9.6

【安装】
运行安装包，依次点击“下一步”，选择安装文件夹，再点击“安装”。安装器会检测并复用已有的 WebView2 Runtime；若未安装，则通过随包提供的微软官方 Bootstrapper 联网下载并安装，因此这种情况下需要互联网连接。VB-CABLE 官方签名驱动也随包提供；首次安装驱动时，Windows 会要求管理员授权，随后请按官方驱动程序的说明完成安装并重启。游戏或 QQ 的麦克风输入请选择 CABLE Output。

支持 Intel/AMD 架构的 64 位 Windows 10 1903 或更高版本、Windows 11，要求 .NET Framework 4.8 或更高版本。支持的新版 Windows 通常已包含所需的 .NET Framework。安装包默认空曲库，不会覆盖个人歌曲、快捷键或设置。

【添加歌曲与快捷键】
首次启动后，在“我的曲库”点击“添加歌曲”，文件选择窗口默认打开程序的 bgm 曲库文件夹；也可以从其他文件夹选择音频。每首歌曲以紧凑卡片展示。点击“快捷键”框，再按字母、数字或功能键完成绑定；“设置起止点”用于配置这首歌由快捷键播放时的范围。删除曲库条目只会将其移出列表，不会删除音频文件。

【歌曲范围和进度条】
“快捷键播放范围”只影响这首歌的单曲快捷键。可以设定开始点和可选结束点；不设开始点则从歌曲开头播放，不设结束点则播放到歌曲结尾。

点击卡片上的“播放”或使用随机播放时，始终播放整首歌曲。播放期间的进度条始终可跳到整首歌曲的任意位置。手动拖动进度条会解除本次播放的锚点限制并继续播放到歌曲末尾；保存的锚点标记仍会显示，锚点本身不会修改。下次按单曲快捷键仍会从保存的范围开始。

【随机播放】
随机曲库扫描 bgm 文件夹中的全部受支持音频文件，包括没有绑定单曲快捷键的文件。可以搜索歌曲并对搜索结果批量勾选或取消；选择自动保存。随机播放采用不重复洗牌队列，播放完当前一轮后重新洗牌；曲目至少有两首时，新一轮第一首不会与上一轮最后一首相同。切换场景不会丢失各场景的队列状态。随机播放始终播放整首歌曲。播放中按随机快捷键或歌曲快捷键即可停止。

【歌单场景】
在主导航的“场景预设”页面切换和管理场景。场景独立保存歌曲、快捷键、播放范围和随机歌单；可以创建空场景、复制、重命名或删除。删除场景不会删除曲库中的音频文件；麦克风、输出设备和音量仍为全局设置。

【歌曲响度和音效包】
播放器首次启动时会在后台分析曲库，并以首个可测量音频作为响度基准；之后只分析新导入的音频，并把响度匹配到已保存的基准。分析过程不显示进度卡片。单曲增益最多提升 11 dB，并将单曲样本峰值限制在 -1 dBFS；相同的增益用于耳机和虚拟通道。静音或无法分析的文件保持原增益。虚拟通道在麦克风与音乐混合后还会使用 -1 dBFS 样本峰值限制器；它不代表真峰值限制。

可以导出当前场景为 .wbgm 音效包。包内包含场景设置及其引用的快捷键歌曲和随机歌单歌曲，不包含绝对路径、全局设备、音量或其他用户设置。导入会先校验清单、文件哈希和压缩包路径，确认后创建一个新场景；同内容音频将复用，名称冲突时不会覆盖已有文件。

【语音混音】
1. 在播放器“语音设置”中选择实体麦克风和 CABLE Input。
2. 在 QQ 或游戏中选择 CABLE Output 作为麦克风/录音设备。
3. 播放歌曲并使用播放器内的信号检测。

虚拟通道只包含所选麦克风与本程序的 BGM，不捕获其他电脑软件的音频。耳机 BGM 和发送给队友的 BGM 可分别调节；两者的滑块范围均为 0–100%，映射到程序数字增益 0–30%，不是校准后的声压分贝。音乐音量不改变麦克风音量。

【依赖与许可】
WebView2 Runtime 使用微软官方 Evergreen Bootstrapper；已有运行时会复用，缺少运行时时需要联网从微软下载。Bootstrapper 使用微软文档支持的静默安装参数，安装后会检查运行时注册信息。运行时由微软自动更新。安装包不再包含完整离线 Runtime。

VB-CABLE 由 VB-Audio 提供，官方网站为 www.vb-cable.com，是 Donationware。随播放器分发的官方驱动保持原样，并在安装界面注明来源和支持方式。用户可通过 VB-Audio 官方产品页了解或捐赠：https://vb-audio.com/Cable/。首次安装驱动需要管理员授权并可能需要重启。卸载播放器不会卸载共享 VB-CABLE 驱动。

【数据位置】
用户设置和导入歌曲保存在 %LOCALAPPDATA%\BgmHotkeyShare。安装包不包含歌曲、录音、开发机路径、个人设备名称或用户配置。卸载会保留歌曲和设置。
